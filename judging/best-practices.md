# Best Practices

## Time Management Essentials for the Notebook

* Thinkcell Gantt Chart
* Kanban planner to help organize the tasks that need to be done&#x20;
  * Kanban planners divide your tasks into differnt stages of completion. For example, there can be a backlog section for tasks that need to be done eventually; a ready section for tasks that a ready to start; a in progress section for tasks that are in progress; a review section to review you task after finishing; and finally a done section.&#x20;
  * heres a link to a more detailed explanation of a Kanban (with pictures): [https://business.adobe.com/blog/basics/what-is-kanban](https://business.adobe.com/blog/basics/what-is-kanban) &#x20;
